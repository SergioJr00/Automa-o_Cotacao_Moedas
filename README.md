# Automação_Cotacao_Moedas

# 📊 Cotação de Moedas e Criptomoedas com Python

Projeto desenvolvido em **Python** para realizar a consulta e análise de cotações de moedas e criptomoedas utilizando uma **API de dados financeiros**.

O projeto realiza a coleta de dados em tempo real e permite consultar informações como **Dólar, Euro e Bitcoin**, além de trabalhar com dados históricos para análise da variação das cotações.

### 🚀 Funcionalidades

* Consulta de cotações em tempo real através de uma API;
* Consulta das cotações do **Dólar, Euro e Bitcoin** em relação ao Real Brasileiro;
* Coleta do histórico de cotação do Dólar dos últimos 30 dias;
* Coleta de dados históricos do Bitcoin em um período determinado;
* Conversão e organização dos valores obtidos pela API;
* Criação de gráfico para visualização da evolução da cotação do Bitcoin.

### 🛠️ Tecnologias utilizadas

* **Python**
* **Requests** — consumo da API e obtenção dos dados;
* **JSON** — tratamento dos dados retornados pela API;
* **Matplotlib** — criação de gráficos e visualização dos dados.

### 🎯 Objetivo

O objetivo do projeto é demonstrar na prática conhecimentos em **Python, integração com APIs, coleta e tratamento de dados e visualização de informações**, simulando um fluxo básico de análise de dados financeiros.

Este projeto faz parte do meu desenvolvimento prático em **Análise de Dados**, com foco na utilização de Python para transformar dados brutos em informações que possam ser analisadas e visualizadas.
